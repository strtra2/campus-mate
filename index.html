1. Nama Project

CampusMate - IPK Calculator & Tugas Tracker

2. Masalah yang diselesaikan dan cara aplikasi membantunya

Mahasiswa sering kesulitan memantau Indeks Prestasi Kumulatif (IPK) secara akurat, menghitung target nilai lulusan (Cum Laude), serta mengelola tenggat waktu tugas kuliah yang berantakan. CampusMate menyelesaikan masalah ini dengan menyediakan web app terpadu: Kalkulator IPK/IPS otomatis per semester, Simulasi Target IPS untuk sisa SKS kelulusan, dan Tracker Tugas & Deadline interaktif yang dilengkapi countdown waktu serta prioritas.

3. AI tool atau coding agent yang digunakan

Gemini 3 Flash — Digunakan untuk merancang arsitektur single-page application (SPA), pembuatan antarmuka UI modern berbasis Tailwind CSS, implementasi kalkulasi matematika IPK/IPS/Target SKS, serta manajemen penyimpanan lokal (Local Storage) dan komponen modal interaktif.

💡 Tips Pengumpulan:

  • Simpan file website ini dengan nama index.html di repository GitHub Anda.
  • Anda bisa mengunggahnya langsung ke GitHub Pages atau Vercel/Netlify untuk mendapatkan **Link Demo Project**.
